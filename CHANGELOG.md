# Changelog

All notable changes to this package will be documented here.

## 0.1.0 - 2026-08-18

- Initial public Node.js SDK.
- Send one email using a published MailEngin template.
- Send personalized bulk email requests.
- Support advanced raw HTML sends.
- Provide TypeScript declarations, CommonJS, and ES module builds.
- Provide structured API, timeout, abort, and network errors.
